# PISSARRA "AVUI TENIM"
# Una línia per producte:   Nom | preu | nota
# El preu i la nota són opcionals. Les línies que comencen per # no surten a la web.
# La data (any-mes-dia) és opcional: si hi és, la web mostra "Actualitzada el ...".
# Si no hi ha cap producte, la web mostra un missatge per preguntar per WhatsApp.
#
# Exemple:
# data: 2026-10-17
# Lluç de palangre | 18,90 €/kg | Ideal a la planxa
# Gamba de Vilanova | 39,00 €/kg
# Musclos | 4,50 €/kg | Nets i a punt
